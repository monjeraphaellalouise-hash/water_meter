→ Test on real device, check permissions

**"Can't connect phone"**
→ Same Wi-Fi network required

**"Build failed"**
→ Run `npm run build` again, check errors

**"Need iOS but have Windows"**
→ Use Option 1 (Add to Home Screen) instead
